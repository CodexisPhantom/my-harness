# my-harness

Personal harness. It holds agents, commands, and rules for daily work.

## Philosophy

One main agent (orchestrator) plus subagents (coder/explorer/librarian/reviewer).
Better structure and productivity.
Security via least-privilege, scoped tools, and review gate.
